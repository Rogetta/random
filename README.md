# random

基于 Qt 6、C++17、Qt Widgets 的 Windows 名单抽取工具。

## 功能

- 文件：加载名单、保存名单、另存名单
- 支持 Markdown（`.md`）名单表格
- 同时兼容简单 CSV / TXT 名单
- 多名单标签页，支持滚动、关闭和 `+` 快捷加载
- 左侧人员列表、右侧人员详细信息
- 筛选字段支持多选
- 不选择筛选字段时，在全部字段中搜索
- 选择多个字段时，在这些字段之间进行“或”匹配
- 「姓名」也是可选筛选字段
- 抽取 / 停止随机抽取动画
- 亮暗主题切换
- 自动加载上一次名单
- CMake / Qt Creator 工程

## Markdown 名单格式

推荐使用 Markdown 表格：

```markdown
| 姓名 | 学号 | 小组 | 性别 |
| --- | --- | --- | --- |
| 王五 | 2024020678 | 26班 | 男 |
| 李四 | 2024020679 | 26班 | 女 |
| 张三 | 2024020680 | 27班 | 男 |
```

第一列必须是「姓名」。

程序保存为 Markdown 时会自动生成上述格式。单元格中的 `|` 会进行转义，因此普通 Markdown 表格内容可以安全保存。

## 多字段筛选

筛选字段下拉框中的字段可以复选。

例如：

- 勾选「小组」+「性别」
- 输入「男」

程序会在「小组」和「性别」两个字段中分别查找，只要任意一个字段匹配，该人员就会进入候选集合。

如果一个字段都没有选择，则恢复为全字段搜索。

筛选得到的候选集合同时用于左侧人员列表和随机抽取，因此抽取不会抽到当前筛选条件之外的人员。

## 构建

需要 Qt 6 和 CMake：

```bash
cmake -S . -B build
cmake --build build --config Release
```

也可以在 Qt Creator 中直接打开 `CMakeLists.txt`。
